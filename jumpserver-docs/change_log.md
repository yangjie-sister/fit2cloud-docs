v5.1.1
------------------------
2026年10月20日


- perf: 调整后台任务记录，创建记录时不再保存原始 args、kwargs，减少不必要的参数持久化
- perf: 增强高可用部署中数据库和 Redis 的持久化启动写保护，覆盖容器重启、重建及故障恢复场景
- perf: 优化高可用重部署完成判定，允许正常复制延迟；调整主备切换等待和恢复协调，减少状态误判


- fix: 完善 Access Token 格式校验，保留其他 Bearer Token 认证方式的回退兼容性
- fix: 修复 Tinker 发布机部署期间的 NLA 配置及 RDP 服务刷新流程，安装前检查组策略并关闭监听器 NLA，安装后再次确认配置；组策略强制启用 NLA 时，中止部署并提示调整
- fix: 修复主备切换、自动重新加入和启动恢复期间，角色回调、操作锁及文件同步确认之间的竞争问题【企业版】
- fix: 完善 MySQL/MariaDB 复制位点与崩溃恢复处理，修复 PostgreSQL 备节点重建时复制槽清理的竞争问题【企业版】
- fix: 修复 MySQL/MariaDB 维护期间的本机管理员凭据恢复与健康检查，避免错误使用对端凭据或过期的业务密码【企业版】

v5.0.0
------------------------
2026年9月17日


- JumpServer 于 2014 年以开源堡垒机项目起步。十余年来持续稳步增长与不断迭代，在资产接入、访问控制与运维审计方面持续完善。2026 年 JumpServer v5.0 的发布标志着全新篇章的开启。
- JumpServer v5.0 推出焕新的原生客户端，为 SSH、RDP、Kubernetes、数据库与 RemoteApp 资产提供统一入口，并支持分屏视图、文件工作区、脚本库及 SFTP Server 连接。
- 新增 AI 辅助能力：命令推荐、实时操作风险告警与自动化审计报告，帮助团队更高效地工作、更轻松地审查运维操作。
- 升级 KoKo TUI：在 SSH 终端中可更便捷地查找资产、选择账号与协议，并在多个会话间切换。
